# Review packs for a Chinese AI model: HSK 2

Open DeepSeek (chat.deepseek.com) and/or Qwen Chat (chat.qwen.ai), start a **new chat for each file**, paste everything below the line, and paste the answer back to Claude.
Each file asks the model to report **problems only**, so the answers stay short. Where two models disagree, that item goes to a human teacher.
Nothing on the HSK 2 side has been checked by a person who reads Chinese; these packs are how that gets done.

| File | What it checks |
|---|---|
| 01-word-list.md | the 197 words: pinyin, glosses, the three missing words, neutral tones |
| 02-grammar-explanations.md | the 18 grammar lessons and the claims I am least sure of, plus the grammar outline question |
| 03-sentences-1-of-4.md | 220 example, exercise and fill-in sentences |
| 04-sentences-2-of-4.md | 220 example, exercise and fill-in sentences |
| 05-sentences-3-of-4.md | 220 example, exercise and fill-in sentences |
| 06-sentences-4-of-4.md | 139 example, exercise and fill-in sentences |
| 07-word-webs.md | character meanings inside words, the opposite pairs and notes, the topic groups |
| 08-questions-for-alibaba.md | practical questions for Alibaba support or documentation (not about Chinese) |
